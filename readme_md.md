# 🚗 Garagem Aberta

Um catálogo automotivo interativo focado no mercado brasileiro. O **Garagem Aberta** foi criado para facilitar a consulta de veículos, permitindo explorar fichas técnicas completas, filtrar modelos e comparar diferentes opções lado a lado de forma simples e rápida.

## ✨ O que você encontra por aqui

* **Catálogo Variado:** Informações detalhadas de carros, motos, utilitários/vans e caminhões.
* **Busca e Filtros Rápidos:** Encontre facilmente o veículo que procura por marca, modelo, ano ou categoria.
* **Galeria Dinâmica:** Exibição automática de fotos reais dos modelos pesquisados.
* **Comparador Lado a Lado:** Selecione diferentes veículos para comparar suas especificações técnicas e ajudar na escolha.
* **Visualização Flexível:** Alterne entre cartões visuais ou uma tabela completa de dados, com acesso a fichas detalhadas de cada modelo.
* **Visual Moderno:** Interface escura (*Dark Mode*) adaptada para computadores, tablets e celulares.
